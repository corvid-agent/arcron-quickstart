How to run (under ten minutes)

  1. Throwaway TestNet account, about 0.2 TestNet ALGO from the dispenser. Not MainNet. Not a real mnemonic.
  2. Copy .env.example to .env and set DEPLOYER_MNEMONIC. .env* is gitignored from commit 1.
  3. pip install -r requirements.txt -r requirements-dev.txt
  4. python -m puyapy contracts/minimal_target.py --out-dir artifacts
  5. python scripts/demo.py — deploy, set_keeper(769891898), request_work(), register run()uint64 with SKIP_AHEAD.
  6. python scripts/observe.py — wait for an execute, print txid and round.
